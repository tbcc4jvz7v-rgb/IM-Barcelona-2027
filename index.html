OneDrive backup & restore

Your training log saves automatically on this device. Use the backup button to send a dated JSON backup to OneDrive.

On iPhone, choose OneDrive in the iOS share sheet. If it is not offered, save the downloaded file to OneDrive using the Files app.

Recommended routine

After each training week, export a backup and save it in a folder named IRONMAN Barcelona 2027 in OneDrive. To restore, choose the backup JSON from OneDrive in the file picker.

This is a GitHub Pages-hosted, local-first app: there is no account login or automatic cloud sync. OneDrive stores your backup file; it does not continuously synchronise the live log. Keep the latest backup in OneDrive. Importing a backup replaces the log currently on this device.
